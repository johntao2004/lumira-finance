# AP01 普通供应商服务费用会计确认（受限切片）

本片仅覆盖CNY、V4自然人凭证模式年度内的普通非现金供应商服务费用。会计来源必须为真实V15已独立确认费用份额的当前净额，全额承接，不允许任意部分金额或另造业务链。验收场景采用同一单据/业务链的600与300份额，费用额度900、独立会计额度800；600占用时300会计提交被拒，不能把两个用途额度相加或自动复制费用额度。

提交产生真实预占及父份额依赖；独立批准授权执行；记账再原子产生两行总账、过账序号、COMMITTED用途、应付未结项与真实记账回执。这三个动作分开，批准不等于已入账。供应商组织登记、当前双账套读取范围、maker/editor与独立审批人真实person主体均按协议核验。历史回执保留冻结的供应商、原件、额度与来源链，不因今天的主数据状态或批准时限变化被伪改为无效，也不拿当前身份回填旧历史。

合法全额会计反向另产生相反借贷的真实凭证，原凭证仍POSTED并保留不可变证明；对应用途和父依赖真实释放、未结项归零。不支持反向再反向。系统余额为已确认本金减会计反向，不等于银行确认的未付款；外部结算仍UNKNOWN/null。没有付款、退款或银行验真宣称。

供应商仅组织声明核验，不是政府KYC。counterparty/1的consumerImplemented=false仍指该主数据协议本身不执行财务；本片AP owncatalog有独立真实会计consumer。旧EV03费用子协议用途元组不改，AP会计额度另审。两个旧响应type枚举显式增加AP_EXPENSE/AP_EXPENSE_REVERSAL；旧NORMAL请求及canonical身份协议不变。

保数据生命周期为dataSets[]、仅PRESERVE。V18增加17个AP表，总业务表127；升级前后整表指纹要求完全一致。场景后的合法可变状态按真实typed事件核验，不能宣称所有127表在业务操作后不变。既有18.1事实保留另列技术generation例外，不篡改历史迁移或旧身份。
